📔 Diario del Comandante — Ruta Norte, Entrada 1
Copenhague, Dinamarca · 1915

Copenhague nos recibió con esa peculiar calma escandinava que esconde una vigilancia permanente. La neutralidad danesa es un filo de navaja: protege tanto a viajeros legítimos como a espías de todas las naciones. Y aquí estamos nosotros, en algún punto entre ambas categorías.

El comerciante Soren Lindqvist nos esperaba en el puerto. Hombre de pocas palabras y mucha desconfianza. Su exigencia fue directa: antes de autorizar el paso hacia el Báltico, necesita ver que la carga de los barcos es coherente. Ningún barco sobrecargado. Ningún barco sin permiso.

"Si vuestros documentos y vuestra carga no coinciden," dijo sin apartar la mirada, "os entrego a las autoridades portuarias. Y ellos tienen contactos en todos los bandos."

CREATE TABLE barcos (
    id_barco        INT PRIMARY KEY,
    nombre_barco    VARCHAR(50),
    bandera         VARCHAR(30),
    capacidad_maxima INT
);

CREATE TABLE cargas (
    id_carga  INT PRIMARY KEY,
    id_barco  INT,
    peso      INT
);

CREATE TABLE permisos (
    id_permiso   INT PRIMARY KEY,
    id_barco     INT,
    estado_permiso VARCHAR(20)
);
