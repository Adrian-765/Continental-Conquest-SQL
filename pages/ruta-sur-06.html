📔 Diario del Comandante
1915–1916 — Rostov · Don · Hacia Moscú

La campaña avanza. Las ciudades clave —Rostov, el Volga, Novocherkassk— se suceden como piezas de un tablero inmenso. A medida que avanzamos, la guerra civil interna se intensifica, la población está exhausta y las rutas ferroviarias y fluviales se vuelven peligrosas.

Ahora se añade un nuevo destino: Moscú. El corazón del poder zarista. La ofensiva hacia la capital exige precisión total. Cada unidad asignada, cada ruta elegida, debe ser calculada antes de dar el paso definitivo.

La misión sigue siendo desestabilizar el imperio desde dentro. Los bolcheviques creen luchar por el pueblo. Nosotros luchamos por el equilibrio de Europa. El mapa de rutas acaba de actualizarse con la ruta crítica.

📋 Estructura de tablas — Enunciado
CREATE TABLE unidades (
    id_unidad    INT PRIMARY KEY,
    nombre_unidad VARCHAR(50),
    tipo         VARCHAR(20),
    soldados     INT,
    municion     INT
);

CREATE TABLE rutas (
    id_ruta      INT PRIMARY KEY,
    destino      VARCHAR(50),
    distancia_km INT,
    prioridad    VARCHAR(10)
);

CREATE TABLE asignaciones (
    id_asignacion      INT PRIMARY KEY,
    id_unidad          INT,
    id_ruta            INT,
    soldados_asignados INT,
    municion_asignada  INT
);
