Verano 1915 — Mar Negro · Novorossiysk

El SS Eleftheria surca el Adriático rumbo al mar Jónico, bordeando la costa griega. La noche es clara y silenciosa; Atenas queda atrás y la inmensidad azul del mar se extiende ante nosotros. La tripulación mantiene un respeto tenso, consciente de la misión.

Tras días de navegación, atravesando el Egeo y doblando los Dardanelos, entramos en el Mar Negro. Cada puerto que dejamos atrás parece una fachada: mercantes, inspectores y banderas neutras esconden ojos vigilantes.

Novorossiysk se perfila en el horizonte. Nos esperan los contactos bolcheviques locales. Nuestra alianza es puramente instrumental. Antes de coordinar los movimientos, debo demostrar que conozco con precisión los datos de cada contacto disponible en la red.

CREATE TABLE red_novorossiysk (
    id_agente        INT PRIMARY KEY,
    nombre_clave     VARCHAR(50),
    nivel_infiltracion INT,
    fiabilidad       DECIMAL(3,2),
    zona_operacion   VARCHAR(50),
    estado           VARCHAR(20)
);

-- 1. Agentes preparados para infiltrarse
SELECT nombre_clave
FROM red_novorossiysk
WHERE nivel_infiltracion >= 4
  AND fiabilidad > 0.7;

-- 2. Estado operativo de cada agente
SELECT nombre_clave,
  CASE WHEN estado = 'activo' THEN 'OK'
       ELSE 'RIESGO' END AS estado_op
FROM red_novorossiysk;

-- 3. Fiabilidad media por zona
SELECT zona_operacion, AVG(fiabilidad)
FROM red_novorossiysk
GROUP BY zona_operacion;

-- 4. Agentes problemáticos
SELECT nombre_clave
FROM red_novorossiysk
WHERE fiabilidad < 0.6
   OR estado = 'comprometido';
